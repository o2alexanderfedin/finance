<the_next_thing_to_know>
**The comma gap, and why it must not be "fixed" in the obvious place.**

Criterion 3 carries `"1,234.56"` from the OCR revision into `123456` cents. Phase 4's parser rejects
that string:

```
parse(2)("1234.56")   = 123456
parse(2)("1,234.56")  -> THROWS: not a decimal number: 1,234.56
```

**That is correct behaviour.** `fjs/types/decimal` is generic and staged for upstreaming into
FunctionalScript; comma grouping is a presentation convention of printed US forms. Plan 05-03 adds
degrouping **beside the dialect conversion**, never inside `fjs/types/decimal`. Relaxing the generic
parser would ship a locale convention upstream.

Criterion 3 also says the conversion happens on **exactly one** revision boundary — if two places can
convert, they can disagree.

Criterion 4 bundles **four independent facts**: same-artifact-same-subject, blank decoding as absent
rather than zero, form revision present, `CORRECTED` readable. One combined leaf proves the least of
them; 05-03 plans a leaf each.
</the_next_thing_to_know>

<decisions_made>

- **Money in a stored JSON document is a string, never a JSON number** (AGENTS.md, absolute). A JSON
  number is an IEEE 754 double before any arithmetic happens.
- **Refusal is a value, not a throw** (Phase 3). fjs's `assert` throws a *bare string*, so
  `e.message` is `undefined` and an `instanceof Error` branch misses every refusal.
- **IRS half-up, ties away from zero** (Phase 4), explicitly not the built-in — which is asymmetric
  across zero and therefore a systematic bias on every loss.
- **`round(sum(x))`, never `sum(round(x))`**, and nothing rounds on construction — otherwise the
  counterexample is unrepresentable.
- **`corrected: option(true)`**, mirroring revision's `archived`. A `corrected: false` blob is
  *rejected*; absence is the only way to say "not corrected". One representation, not two.
- **Subjects are content-derived and permanent** — a subject cannot be renamed and CAS has no delete.
- **We own FunctionalScript.** A missing *generic* capability means an fjs release, never
  app-specific glue; a generic module is written here staged for upstreaming (AGENTS.md line 18).
- **`@ts-nocheck` is confined to one root-level cross-process harness** — zero under `fjs/`. Typing
  `node:child_process` needs `@types/node`, forbidden as a hard stop. Recorded in
  `fjs/todo/upstream-node-spawn-effect.md`.
</decisions_made>
