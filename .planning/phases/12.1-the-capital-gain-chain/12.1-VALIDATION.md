# Phase 12.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `12.1-RESEARCH.md` § "Validation Architecture". **`12.1-CONTEXT.md` is
> authoritative on all scope counts** (six kinds; 12/38/50).

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | FunctionalScript Emergent Testing — every module exports its own `proof`, discovered ONLY by the root `all.test.js` |
| **Config file** | none — discovery walks the project via `loadModuleMap` |
| **Quick run command** | `node --test 2>&1 \| grep -c '^✔ import("./fjs/'` |
| **Full suite command** | `npm test` (`tsc && node --test`) |
| **Estimated runtime** | ~60–90 seconds full suite |

> **`node --test <some .f.js>` is a documented FAKE PASS.** Only root discovery registers
> proofs. **Never gate on `npm test`'s raw total** — it includes ~2,100 vendored
> `functionalscript` proofs and moves with submodule checkout state. Baseline entering this
> phase: **629** project-local proofs.

---

## Sampling Rate

- **After every task commit:** `node --test 2>&1 | grep -c '^✔ import("./fjs/'` — confirm
  the count rose by the number of leaves that task added. A flat count after a task that
  claims new proofs is a failure, not a rounding error.
- **After every plan wave:** `npm test` (full `tsc && node --test`).
- **Before `/gsd-verify-work`:** full suite green **plus** the mutation sweep below, each
  mutation watched failing. AGENTS.md: *a proof is not known to work until you have watched
  it fail.*
- **Max feedback latency:** ~90s.

## Mutation Gates

Each must be **watched failing**, and the executor must record **which leaf and which
assertion** reddened — Phase 12's M3 reddened a fixture assertion sitting in front of the
comparison it appeared to guard, which is not the same thing.

| # | Mutation | Must redden | Guards |
|---|----------|-------------|--------|
| **M1** | In the Form 8949 gain computation, replace the absent-basis refusal with `centsFromString(basis ?? '0.00')`. Fixture: `box5NoncoveredSecurity: true`, `box1eCostOrOtherBasis` **omitted**, `box1dProceeds: '10000.00'` | A **real production** proof of the refusal. Post-mutation the return silently computes a $10,000.00 gain | **Criterion 3a / DOC-07** — the direct successor to `fjs/document/1099b`'s proof-local `criterion2GainConsequence` |
| **M2** | Swap the boolean feeding `box2ShortTermGainOrLoss` / `box2LongTermGainOrLoss` | A proof asserting **Schedule D line 7 AND line 15 separately** — not line 16's total | The equivalent-mutant trap: moving a gain between short and long-term nets to the **same** total, so a total-only proof cannot see it |
| **M3** | Swap `fjs/tax/line16` branch order so 2c (QDCGT) precedes 2a (SDTW) | Worked Example 1 must change **value**, not merely tag — `scheduleDTaxWorksheet` vs `qdcgt` now return **different cents** | The 2a-before-2c ordering, which until now could only be held down by the method tag |
| **M4** | Remove one kind from `modeledKinds` without touching `expectedModeledKindCount` | The hand-typed count assertion | The second-source guard — `.length` alone cannot catch a removal |
| **M5** | Revert Form 1040 line 3a to `declaredZero` while leaving the scope reclassification in place | A proof that dividend income reaches line 3a | **The atomicity constraint** — this is the exact half-change that makes the engine report a confident zero |
