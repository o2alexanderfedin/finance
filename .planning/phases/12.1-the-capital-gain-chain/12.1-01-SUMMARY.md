## Mutation Gate M1 — Watched Failing (ROADMAP criterion 3a)

**Mutation applied** (Task 2, in `fjs/form8949/module.f.js`'s `form8949` function): replaced the absent-basis refusal

```js
const basis = box.box1eCostOrOtherBasis
if (basis === undefined) {
    return absentBasisRefusal(document.documentHash)
}
```

with

```js
const basis = box.box1eCostOrOtherBasis
if (document.documentHash === '\0mutation-gate-m1-sentinel-never-matches') {
    return absentBasisRefusal(document.documentHash)
}
const resolvedBasis = basis ?? '0.00'
```

(and the two downstream reads of `basis` changed to `resolvedBasis`), so the gain is computed as `centsFromString(proceeds) - centsFromString(basis ?? '0.00')` — conflating absent basis with zero basis — exactly as specified. The sentinel-comparison form (rather than a bare `if (false)` or `x && false`) was necessary to keep `absentBasisRefusal` referenced without tripping `tsc`'s `TS7027` unreachable-code-detection on a statically-`false` literal condition, per AGENTS.md's "the mutation that deletes the last use of a binding does not compile" — a real compile failure hit and worked around during this task, recorded here as the AGENTS.md rule predicts.

**Which leaf reddened:** `import("./fjs/form8949/module.f.js").proof.absentBasisRefusal.genuinelyAbsentBasisRefusesRatherThanComputingAGain()` — a real production proof inside `fjs/form8949/module.f.js`'s own proof tree (not a fixture-local helper, not a copy of `fjs/document/1099b`'s proof-local `criterion2GainConsequence`).

## Issues Encountered

- The first mutation form tried (`if (basis === undefined && false) { return absentBasisRefusal(...) }`) failed `tsc` with `TS7027: Unreachable code detected` — `tsc`'s dead-code analysis statically folds `x && false` to the literal type `false` and flags the guarded `return` as unreachable, which per AGENTS.md means the mutation measures the compiler, not the suite. Fixed by replacing the literal-`false` condition with a runtime string comparison against a sentinel that can never match a real `documentHash` (`document.documentHash === '\0mutation-gate-m1-sentinel-never-matches'`) — this compiles cleanly (not statically reducible to `false`) while keeping `absentBasisRefusal` referenced, satisfying both "must still typecheck" and "must not orphan the binding."
