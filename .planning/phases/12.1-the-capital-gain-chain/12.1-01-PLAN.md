<objective>
Build `fjs/form8949/module.f.js`: a standalone pure module that derives Form 8949 categories
(A, B, D, E — the four categories this project's `vnd.fjs.1099b` dialect can drive; C and F
require no-1099-B property and are out of scope) from each stored 1099-B document's own boxes,
sums each category's gain into a total, and returns a graceful tagged refusal — not a computed
gain — the moment a document cannot be honestly categorized or computed.

Purpose: This is the first of the phase's three new modules and the one every downstream
module (`fjs/schedule/d`, Wave 2) consumes. It also carries two of the three "no analog in
this repo" pieces PATTERNS.md identifies: the category-derivation-plus-cross-check idiom, and
the absent-basis/box-1f/box-1g computation-level refusal (CONTEXT.md Decisions 2.4, 2.6, 1.4).
Output: `fjs/form8949/module.f.js`, exporting `form8949` and its `Form8949Outcome` tagged
union — the contract Plan 12.1-03 (Schedule D) builds against.
</objective>

     module's own docstring, because Plan 12.1-03 will read this file expecting exactly this. -->

```
Stored<T>                     = { readonly documentHash: string, readonly value: T }
CategoryTotal                 = { readonly value: bigint, readonly sources: readonly Source[] }
Form8949Ok                    = { readonly kind: 'ok',
                                   readonly categoryA: CategoryTotal,  // short-term, basis reported
                                   readonly categoryB: CategoryTotal,  // short-term, basis NOT reported
                                   readonly categoryD: CategoryTotal,  // long-term, basis reported
                                   readonly categoryE: CategoryTotal } // long-term, basis NOT reported
Form8949Error                 = { readonly kind: 'error', readonly message: string }
Form8949Outcome               = Form8949Ok | Form8949Error
export const form8949: (brokerageForms: readonly Stored<OneZeroNineNineB>[]) => Form8949Outcome
```
Each `CategoryTotal.value` is the SUM of `(proceeds − basis)` in cents for every document
landing in that category; `sources` carries one `Source` entry per box actually read (so two
per contributing document: `box1dProceeds` and `box1eCostOrOtherBasis`).
