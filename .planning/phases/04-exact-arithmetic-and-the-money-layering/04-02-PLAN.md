From `node_modules/functionalscript/fjs/asserts/module.f.js`:
- `assert: (v: boolean, msg?: unknown) => asserts v` — throws `msg` if `v` is `false`; narrows any
  boolean *expression* passed as `v`, e.g. `assert(m !== null)` narrows `m` from
  `RegExpExecArray | null` to `RegExpExecArray` for the rest of the enclosing scope — no manual cast
  needed.
- `assertNotNullish: <T>(a: T | null | undefined, msg?: unknown) => T` — needed because
  `RegExpExecArray`'s element type is a plain `string`, but under this project's
  `noUncheckedIndexedAccess`, destructuring positions out of it (`const [, sign, intPart, fracPart]
  = m`) types each binding as `string | undefined`. `sign` and `fracPart` are legitimately optional
  (the sign group and the fractional group are both `(...)?` in the pattern) and can be used as
  `string | undefined` directly (`sign === '-'`, `fracPart ?? ''`). `intPart` is not optional — the
  pattern's `(\d+)` group is mandatory — so narrow it explicitly with
  `assertNotNullish(intPart, ...)` rather than a non-null assertion (`intPart!` is not valid JS
  syntax in a `checkJs` `.js` file; only real JSDoc-typed runtime narrowing works here). This is the
  kind of strict-mode obstacle AGENTS.md says to solve without relaxing a flag — do that, don't
  disable `noUncheckedIndexedAccess`.
- `assertEq: <T>(a: T, b: T, msg?: unknown) => void` — `===` comparison.

From Plan 01's `fjs/types/rational/module.f.js` (read the file itself for full context — this is
the shape Task 3 composes against):
- `of: (numerator: bigint) => (denominator: bigint) => Rational`, `ofInt: (n: bigint) => Rational`,
  `multiply: (a: Rational) => (b: Rational) => Rational`, `halfUp: (a: Rational) => bigint`.
- `Rational = readonly [bigint, bigint]` — `[numerator, denominator]`.

House style, from `fjs/types/rational/module.f.js` (Plan 01) and `fjs/exec/module.f.js`:
- Type imports as a top-level `/** @import { Name } from '...' */` comment, never inline

- Emergent Testing's `throw`-key convention: a leaf nested under a property literally named `throw`
