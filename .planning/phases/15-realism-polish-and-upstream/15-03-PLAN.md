source, materialize, load) but must stop ONE step earlier: it must never call
`loaded.report(...)`.

From `fjs/server/fjs_run/module.f.js` (the exact CAS-read-by-hash sequence to reuse for step 1-2,


From `fjs/guest/materialize/module.f.js`'s own proof, the technique to mirror EXACTLY for the
never-executes proof: `dirtySourceIsRefusedWithoutEvaluatingTheModuleBody` places a `JsModule`
fixture (a plain zero-argument function `virtual`'s `import_` invokes on import) that sets a
`spy.evaluated = true` flag, then asserts the flag stayed `false` when the gate refused before
`import_` ran. `fjs_check`'s own proof needs a DIFFERENT spy point: the module body's factory
function running on import is EXPECTED and harmless (that is unavoidable — `import()` always runs
top-level code); the spy must instead sit INSIDE the returned `report` FUNCTION itself, so the
proof can assert that function was never CALLED, even though the module around it was imported.
