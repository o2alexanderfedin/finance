| Boundary | Description |
|----------|--------------|
| Stored document JSON -> guest program | Untrusted (agent-authored, taxpayer-derived) content parsed by the guest's own `JSON.parse` |
| Guest program result -> host result blob | The guest's returned object crosses into CAS via the SAME `fjsRunTool.handle` path every other report uses; no new mechanism |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-15-01 | Tampering | payer report claims a total not traceable to a real document | mitigate | Every payer total carries a non-empty `sources` tuple citing `documentHash`/`boxPath`, unit-proved in Task 1 |
| T-15-02 | Information Disclosure | payer report silently reads/aggregates data outside its stated two-dialect scope | accept | Deliberate, documented scope boundary (1099-INT box1, 1099-DIV box1a only); a document of any other dialect is skipped, never guessed at |
</threat_model>
