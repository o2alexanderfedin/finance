From `fjs/run/module.f.js`:
```
export const dialect = 'vnd.fjs.run'
export const validate: (value: Unknown) => Result<Run, RunError>
/** @typedef {{ dialect, programHash: string, args: readonly string[], pinned: boolean,
    subject?, parents?, status: 'ok' | 'error', inputs: ..., resultHash?: string, error?: string }} Run */
```
An `ok` run always has a non-empty `resultHash` and never an `error` field; an `error` run always
has an `error` message and never a `resultHash` — already enforced by `Run.checkReferences`, so
this module can trust it.

From `fjs/report/line/module.f.js`:
```
/** @typedef {{ readonly documentHash: string, readonly boxPath: string, readonly value: string }} Source */
/** @typedef {{ readonly value: bigint, readonly sources: readonly [Source, ...Source[]], readonly rule: string }} ReportLine */
export const applyWholeDollarElection: (elected: boolean) => (lines: readonly ReportLine[]) => readonly ReportLine[]
```
`applyWholeDollarElection` is NOT part of `guestCtx` — confirmed absent — so a guest program
cannot have applied it; this diff module must apply it itself, host-side, over raw cents.

Reading a `vnd.fjs.run` record back out of CAS by hash — the EXACT sequence to reuse (adapted
from `fjs/server/fjs_run/module.f.js`'s own `assertPersistedErrorRunRecord` test helper, already
proven against real CAS content):
```javascript
import { cBase32ToVec } from 'functionalscript/fjs/basen/cbase32/module.f.js'
import { collectRead } from 'functionalscript/fjs/cas/module.f.js'
import { utf8ToString } from 'functionalscript/fjs/text/module.f.js'
import { validate as validateRun } from '../../run/module.f.js'

const readRunRecord = cas => runHash => {
    const vec = cBase32ToVec(runHash)
    if (vec === null) { return pure(error(`not a decodable run hash: ${runHash}`)) }
    return mapStep(collectRead(cas.read(vec)), readResult =>
        readResult[0] === 'error'
            ? error(`run record not found: ${runHash}`)
            : validateRun(JSON.parse(utf8ToString(readResult[1]))))
}
```

The stored RESULT a run's `resultHash` points at, for a report that returns a structured value
(never a bare string), is a JSON object keyed by line name, each value shaped
`{ value: string, sources: readonly Source[], rule: string }` — the wire projection of
`ReportLine`, exactly as `fjs/report/line/module.f.js`'s own
`wireProjectionRoundTripsThroughJson` proof exhibits it. Validate this shape with rtti's
`record({ value: string, sources: array({ documentHash: string, boxPath: string, value: string
}), rule: string })` (the same `record(...)` combinator `fjs/media/revision/module.f.js` uses for
its own `lock` map).
