<objective>
Make a stored blob safely materializable: gate its import specifiers before anything runs, name it
by content hash so the ESM cache cannot silently re-run an earlier program, and reach `import()`
through the effect so the entire path is testable with no filesystem.
</objective>

  <action>
    `checkSpecifiers` takes the allow-list as a parameter (empty for guests) rather than hardcoding
    reject-all — the parameter costs one line, and a function named for an allow-list that cannot
    express one is a name that stops being true. Match every specifier form: `from 'x'`,
    `import 'x'`, `import('x')`, `export ... from 'x'`. Use negated character classes, not lazy
    wildcards, so matching is linear.

    `programFileName` is `${hash}.mjs` and nothing else. `programPath` is separate because
    virtual's `import_` accepts only a single-segment path.

    `loadProgram` checks, then `step(import_(path), ...)`. No raw `import(...)` expression.
  </action>
