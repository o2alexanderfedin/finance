    - `dialect = 'vnd.fjs.run'`, `mediaType = 'application/vnd.fjs.run+json'`.
    - `runSchema` spreads `base(dialect)` first, then: `programHash: string`,
      `args: array(string)`, `pinned: boolean`, `subject: option(string)`,
      `parents: option(array(string))`, `status: or('ok', 'error')`,
      `inputs: array({ command: string, payload: array(string) })`,
      `resultHash: option(string)`, `error: option(string)`.
    - `checkReferences` (semantic, RTTI cannot express these): `programHash` non-empty
      (trimmed); every `inputs[].command` is one of `casOpNames` (import from
      `../guest/module.f.js`; an unrecognized command name is a `checkReferences` error, since a
      genuine run record can never have observed a command outside the frozen four); if
      `status === 'ok'` then `resultHash` must be present (non-empty) and `error` must be
      absent; if `status === 'error'` then `error` must be present (non-empty) and `resultHash`
      must be absent — a record cannot claim both an answer and a failure.
    - No field in this schema stores a computed monetary figure as anything but a hash/string —
      `resultHash` names where the actual result lives in CAS (EXACT-05 is not re-litigated
      here because this record carries no numeric value directly).
    - `validate = value => structural check, then checkReferences` — identical shape to
      `1099int`'s `validate`.
  </behavior>
  <action>
    Create `fjs/run/module.f.js` mirroring `fjs/document/1099int/module.f.js`'s four-stage
    template (dialect -> mediaType -> schema -> structural validate -> semantic checkReferences
    -> composed validate). Import `base` from `../document/base/module.f.js`, `casOpNames` from
    `../guest/module.f.js`, and `string`/`array`/`boolean`/`option`/`or` from
    `functionalscript/fjs/types/rtti/module.f.js`. Export the derived TS type as `Run` via
    `Ts<typeof runSchema>` (same pattern 1099int uses for `OneZeroNineNineInt`). Write a module
    header explaining why this is a dialect rather than a bespoke record shape (mirrors
    `vnd.fjs.revision`; the base/spread convention; `inputs[]` is populated exclusively from
    `interpret`'s observed reads, never program-declared — state this as a documented invariant
