<objective>

program hash, and an import failure — each surface as a tool-level `errorResult` through the
FULL `fjsRunTool.handle` (assembled in Plan 06), never as a process crash or a dropped
connection, and each still produces a persisted `vnd.fjs.run` record with `status: 'error'`.

crash, never a dropped connection." Plan 06 already builds the error-mapping code path this
plan exercises; this plan is primarily additive proof coverage confirming that path holds for
each named failure class individually, plus the "session survives" half the criterion also
requires.

verifiable, each asserting session survival.
