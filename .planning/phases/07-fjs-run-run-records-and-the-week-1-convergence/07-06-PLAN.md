Assemble the `fjs_run` MCP tool (EXEC-08, EXEC-10, EXEC-11, PROV-03): compose Plan 05's
materialize/snapshot mechanisms with Phase 6's `loadProgram` and Phase 3's `interpret` into
`executeRun`, then wrap it in a tool handler that — never the guest — writes the result and the

specifically requires an ADVERSARIAL proof — a program that reads a document it does not cite,

(already true and unchanged).
