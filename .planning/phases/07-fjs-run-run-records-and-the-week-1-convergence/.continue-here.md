# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Every one below was discovered through an actual failure in this
> session, not predicted. Acknowledge each explicitly before proceeding.

- [ ] **CONSTRAINT: Never gate on `npm test`'s total pass count.** Root discovery walks the
      `functionalscript` submodule and sweeps in ~2177 vendored proofs. The total is ~2333 in the
      main checkout and ~187 in a worktree where the submodule is uninitialized — for reasons
      having nothing to do with this project's code. *Structural mitigation:* every phase gate
      uses `node --test 2>&1 | grep -c '^✔ import("./fjs/'` (project-local only, currently
      **185**), compared against a freshly measured baseline — never a literal carried across
      checkouts.

- [ ] **CONSTRAINT: A proof that mirrors the code's own mistake proves nothing.** `executeRun`
      wrote a program to `<home>/.fjs-run/<hash>.mjs` and imported a bare `<hash>.mjs`. Real Node
      resolves a bare specifier against `process.cwd()`, so real `fjs_run` calls failed. All 185
      virtual proofs missed it because each keyed its `JsModule` fixture at the *same wrong bare
      name the code asked for*. *Structural mitigation:* derive both paths from one expression so
      they cannot drift; and per TEST-01/03, every seam gets real-process coverage.

- [ ] **CONSTRAINT: `cd` into `./functionalscript` silently redirects everything that follows.**
      Shell cwd persists across Bash calls, and the submodule is a complete, valid checkout of a
      *different* project. Commands keep succeeding and answer about the wrong repo — this session
      briefly reported the build broken (`node_modules` missing, 0 proofs) while standing in it.
      *Structural mitigation:* use absolute paths; verify with `pwd` when anything looks surprising.

- [ ] **CONSTRAINT: `node --test <source-file>` is a documented FAKE PASS.** Emergent Testing only
      registers proofs reached through root `all.test.js`. A proof file that exists but is never
      imported registers **zero tests and passes silently**. *Structural mitigation:* only ever run
      `npm test` / `node --test`, and confirm the project-local count *rose*.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| Tautological proof | A proof asserts against the same wrong value the implementation uses (the `programFileName` path mismatch). Green forever, proves nothing. | blocking | Real-process coverage per TEST-01/03; derive paired values from one expression. |
| Vacuous gate | A threshold already satisfied before any work (`total > 134`, when the total was 2311). | blocking | Project-local proof count vs a freshly measured baseline. |
| `instanceof Error` branch | fjs's `assert`/`unwrap`/`match` throw **bare values**. `typeof e === 'string'`, `e instanceof Error === false`, `e.message === undefined`. Already bit this project once. | blocking | Read caught values directly. Never branch on `instanceof Error`. Upstream: functionalscript#1432. |
| Wrong-layer assertion | Proving `interpret`/`loadProgram` returns `error(...)` when the claim is that the *tool* returns `errorResult`. Phases 3 and 6 already prove the inner layers. | advisory | Drive failure classes through the fully assembled handler, each as its own leaf. |
| Hardcoded expected value | A literal expected total passes even when the logic is wrong in a way that matches. | advisory | Compute expected values in the test from seeded inputs. |
| Silent submodule commit | The submodule pointer moved twice mid-session (a second author). | advisory | Never `git add` the `functionalscript` path. |
