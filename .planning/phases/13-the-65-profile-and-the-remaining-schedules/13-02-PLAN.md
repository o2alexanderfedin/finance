<objective>
Complete Wave 1 (TAX-10): wire `vnd.fjs.1099r` and the new SSB worksheet into Form 1040 lines
4a/4b, 5a/5b, 6a/6b and 25b, thread the `iraDeductionDeclared` circularity refusal, then —
atomically, in the same task — reclassify the four kinds this wiring makes computable, and
prove end to end that a real 65+ return now produces a number it could not produce before.

Purpose: This is the slice's vertical cut — the point at which a return with retirement and
Social Security income actually computes AGI correctly, which every later slice's phase-out
arithmetic depends on (CONTEXT.md Decision 6.2).

Deviation from Decision 5.1's stated rationale, recorded here rather than left silent: Decision
5.1 justified `iraDeductionDeclared` partly as letting a return with, say, only an
HSA-deduction Schedule 1 adjustment compute normally — but `scheduleOneAdjustments` stays
permanently refused for the whole of this phase (13-RESEARCH.md Open Questions 1 and 2,
ROADMAP.md's Wave 5 finding, 13-11's objective), so no HSA-only adjustment is reachable
regardless of this field. The field still earns its place as a defence-in-depth refusal for a
profile that sets `iraDeductionDeclared: true` without declaring `scheduleOneAdjustments` at
all — the mechanism stands; only its originally-stated motivating example does not apply this
phase.

Output: a 65+ single filer with SSA-1099 + 1099-R income computes real lines 4a-6b/9/11b/25b;
`iraDistributions`, `pensionsAndAnnuities`, `socialSecurityBenefits`,
