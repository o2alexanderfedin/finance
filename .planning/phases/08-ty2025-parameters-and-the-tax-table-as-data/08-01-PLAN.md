<objective>
Store every TY2025 tax parameter this project needs — the standard deduction (OBBBA-revised),
the aged/blind additional amounts, the dependent standard-deduction cap, the ordinary rate
brackets for all five filing statuses (including Estates & Trusts), and the capital-gains rate
breakpoints — as a compiled-in data module, with each individual parameter carrying its own
per-parameter citation object rather than one document-level citation string.

Purpose: TAX-01 requires the engine to consult data with a citation instead of a model recalling
a figure. Per 08-CONTEXT.md, "Rev. Proc. 2024-40 as modified by Rev. Proc. 2025-32" is true of
exactly one thing — the basic standard deduction — and false of everything else in this set; a
single shared citation string would misstate the source for most entries.
Output: `fjs/tax/params/module.f.js`, a new compiled-in data module (not a `vnd.fjs.*` CAS
document dialect — per 08-CONTEXT.md's decision, tax-year parameters are code-versioned reference
data shipped with the server, not a taxpayer document validated through `fjs/document/base`).
</objective>
