<objective>
Build the combined inventory of every threshold this phase's data introduces — ordinary-bracket
ceilings across all five filing statuses, capital-gains breakpoints across all five, and the Tax
Table's own band-width transition points — and generate a `threshold − 1¢` / `threshold` /
`threshold + 1¢` proof triple for every one of them, mechanically, from the threshold list itself.

Purpose: TAX-04 requires boundary proofs at every threshold in the parameter data. Per
08-CONTEXT.md, these must be generated data-driven over the stored threshold list so a threshold
added later is covered automatically — hand-written named leaves would drift, exactly as
07-08's own `vocabularyIsFrozenAtFour` proof had to move away from a hand-maintained assertion.
Output: `fjs/tax/boundary/module.f.js` — a generic, tax-agnostic boundary classifier and the
generated proof over the combined threshold list.
</objective>

    how many stored boundaries `valueCents` has reached or passed). Document explicitly in this
    function's own comment that it encodes no tax rate, no money computation, and no rounding —
    it is a pure counting function over a list of cutoffs, deliberately NOT sharing any code path
    with `fjs/tax/table/module.f.js`'s `cumulativeBracketTaxCents`/`generateRow`, so a boundary
    proof built on it cannot inherit that module's own bugs (T-08-01's non-shared-code-path
    discipline extended to this module).

    scope: `const taxParams2025 = taxParamsByYear[2025]` immediately followed by
    `assert(taxParams2025 !== undefined, 'expected TY2025 parameters to be present in
    taxParamsByYear')` (`assert` from `functionalscript/fjs/asserts/module.f.js`). This project's
    `tsconfig.json` sets `noUncheckedIndexedAccess: true`, so indexing `taxParamsByYear[2025]`
    yields `TaxParamSet | undefined` even for the literal key `2025` — the open index-signature
    type `fjs/tax/params/module.f.js` declares does not narrow away on its own. Every reference
    below uses `taxParams2025`, never a second `taxParamsByYear[2025]` index. Do NOT use a
    non-null assertion (`taxParamsByYear[2025]!`) or a type cast to silence the compiler here —
    both are banned by AGENTS.md's hard rules; `assert` is the only compliant narrowing path, and
    it throws a bare string, never an `Error` — nothing downstream may branch on
    `instanceof Error`.

    Build `allThresholds`, an array of `{ label: string, cents: bigint }`, assembled from three
    sources, each parsed via `centsFromString` from the exact string already stored in the two
    imported modules — never re-typed as a new literal in this file:
    1. Every DEFINED (non-`undefined`) `ceiling` across every status in

       final entry's `lessThan` (`'100000.00'`) — labeled e.g. `` `taxTableBand:${value}` ``.
