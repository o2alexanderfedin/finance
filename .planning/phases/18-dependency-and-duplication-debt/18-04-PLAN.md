phase from Phase 19's code review) into named `node:test` subtests via `await t.test(...)`, so a

its concern. None is added, removed, or weakened. The shared real server process, its stdout/stderr
parsing, and its JSON-RPC helper functions stay in the outer `test()` scope, created once, and every
subtest reads them by closure — no `describe`/`before`/`after` (no root-level `*.test.js` file in
this repo uses them, so introducing one now would be a new convention this file does not need).
