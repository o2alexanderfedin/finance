## Critical anti-patterns — every row happened, most of them this session

| Pattern | What happened | Prevention |
|---|---|---|
| **A count true of the part, false of the whole** | The `fjs/todo/` note count was wrong in **four places at once**: four branches each deleted notes and each wrote the number it saw, so every count was right when written and all were wrong after merging. | Derive it. Both files now say `ls fjs/todo/*.md`, never read a number. |
| **A check that fails on a healthy tree** | **Three this week, all mine.** An inverted ancestry check; a no-`try` grep scoped to `fjs demo` when `demo/demo.js` has always had one; a measurement recipe excluding `.planning` after a gate started reading it. | After changing any check, run it once against a tree you *know* is green. A command that complains when nothing is wrong trains the reader to ignore it. |
| **Believing my own empty result** | I ran a containment loop over twenty branches, got nothing, and concluded they were independent. They were **one linear chain** — `form-2555-impl` contained every other. An empty result is a claim and deserves the same doubt as a full one. | Verify a negative before acting on it. |
| **Repeating an excuse instead of checking** | `type-level/` was called "another session's work, don't touch" **four times**, by me. Its README says "kept in the repo". It had been type-checked by `tsc` the whole time. | Open the file before writing the excuse a second time. |
| **`tsc` in a worktree lies, both directions** | It binds to the PARENT checkout's `node_modules`: falsely **green** (0 errors on a broken tree) if the parent has an older dep, falsely **red** (1935 errors on a clean tree) if the worktree has no `node_modules` at all. Cost two agents an hour each. | `npm ci` in the worktree, verify once with `--traceResolution`, or measure from an rsync'd copy outside the parent tree. |
| **`gh pr merge` without a number** | Takes the *current branch*, not the PR just created. Silently merged the wrong thing twice. | Always pass the PR number. |
| **A green suite hiding lost coverage** | Twenty leaf names vanished in one merge. All twenty were explained — renames carrying counts, and four 1099-G leaves legitimately retired because Schedule F now models farm income. But nothing would have flagged it. | AGENTS.md's coverage-audit recipe: diff leaf NAMES, then assertion counts per file. |
| **A note whose remedy is wrong** | `upstream-mcp-protocol-version-negotiation` was wrong **twice** — its premise misread the MCP spec, and both proposed remedies would have broken negotiation. | Worse than no note. Type-check or run a proposed fix before recording it. |
