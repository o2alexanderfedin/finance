## Next: Phase 21 — The Last Mile. Read its ROADMAP entry before writing anything.

**The obvious implementation is forbidden, and that is the whole design content of the phase.**
A server tool that reads stored documents, assembles `Form1040Inputs` and calls `form1040Report`
is precisely the `finance_compute_1040` tool REQUIREMENTS.md rules out — *"would destroy the
thesis permanently. The agent would call it and never author a program again."*

**The 2026-08-15 handoff described the last mile in exactly those forbidden terms**, and it would
have been built that way if the persona survey had not re-read the Out of Scope list. If you are
resuming from a summary rather than from this file, that is the single most likely way to go
wrong.

The route that preserves the thesis: `guestCtx` already carries pure non-effect helpers
(`step`, `pure`, `centsFromString`, `centsToString`) beside the four frozen CAS commands, and
`_CasOpIsExactlyTheFourCommands` pins the **effect** vocabulary, not the context. The engine joins
that pure list. The agent still authors the program. **The effect whitelist must not widen by one
entry — criterion 2 makes that checkable by mutation.**
