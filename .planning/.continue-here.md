## Critical anti-patterns — every row is an actual failure

| Pattern | What happened | Prevention |
|---|---|---|
| **`git push` succeeding while doing nothing** | An agent run **un-isolated in the main checkout** did `git checkout -b` and left HEAD on its branch. Three merges landed there; three `git push origin develop` were silent no-ops. Caught only because **main's test count came back 2185 instead of 2242** — a number, not a ref check. | Never run an agent un-isolated in the main checkout. After any merge, verify `git rev-parse develop` equals what you expect. |
| **A workaround that works is the most expensive bug** | The proof suite ran **twice** for months, recorded as a "double-counted *metric*, severity advisory, remedy: de-duplicate". It was double-*run* — `node --test` discovered the vendored submodule's `all.test.ts`. ~53s per run. | Test the diagnosis, not just the symptom. A documented workaround removes all pressure to look again. |
| **A total cannot see a swap** | A two-field transposition and a passive/non-passive column swap each left whole suites green — `(d)+(f)` commutes. | Assert the columns and the `boxPath`, never only the sum. |
| **A count true of the part, false of the whole** | Eleven occurrences. Two registries both 23 long and not the same 23; a hand-typed list three short; the proof floor stale by 1108. | Only a **comparison** stops it. Naming the hazard in a comment failed three times; `theHandTypedListNamesEveryModeledKind` and `dialect_parity` each caught a real omission within a day. |
| **A stale worktree** | Four agents were handed worktrees cut **265 commits** stale and burned most of their budget discovering it. | Make base verification the first instruction: `git checkout -B "$(git rev-parse --abbrev-ref HEAD)" origin/develop && npm ci`. |
| **Context % in hook output is the PARENT's** | An agent stopped after 18 tool calls believing it was at 72%. | Tell subagents to ignore it. |
| **A tick needing a paragraph of caveats** | Phase 25 checked TAX-27 while its own prose said the credit did not compute. | If the caveat is needed, leave it unchecked. |
