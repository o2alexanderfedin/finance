## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention |
|---|---|---|---|
| Subagent dies mid-review | ~8 agents died in one hour to machine sleep, and the ones that died were inside long `advisor()` calls | blocking | Brief every review subagent: **do NOT call an advisor, do NOT spawn sub-agents.** Order checks by priority and say "report as soon as you have answers to the first N" |
| Chasing moving heads | PR heads move every few minutes; several moved twice inside one review | advisory | Tell the agent not to chase — finish measurements, re-read the head once before reporting, state which SHA the findings are against |
| Read-and-agree on docs PRs | For a docs-only PR the analysis *is* the deliverable; a plausible-sounding claim that doesn't reproduce is the defect | blocking | Verify every citation, count and line range against the tree. Retargeted line numbers get read by content — a swap of one wrong number for another is the failure mode |
| Proof reviewed only at head | A proof change can look like added coverage while actually losing some | blocking | Run each mutation on **base and head**. A mutation killed at base but surviving at head is the headline finding |
| `git log --all` for collisions | It sweeps fetched PR refs, so unmerged branches look like history — this produced a false "two files share a number" finding once | blocking | Check "already used" claims against `origin/main` specifically |
| Stale declaration files | `.d.mts`/`.d.ts` shadow `.mjs` sources and make a type claim untestable | blocking | Before any `tsc` probe: `find . -path ./node_modules -prune -o -name '*.d.mts' -print -delete` (same for `*.d.ts` except `types.d.ts`) — the prune matters, `node_modules` may be a symlink into the shared clone |
